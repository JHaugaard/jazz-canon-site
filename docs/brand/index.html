7 · Clear space, min size, usage

Clear space: keep padding ≥ the height of one spine around the mark/lockup.

Min size: mark ≥ 24px tall; below that use the favicon glyph. Horizontal lockup ≥ 120px wide.

Light scheme only — no dark/reversed variants are part of the system, by design.

  • ✓ Mark in full colour on paper or white.
  • ✓ Amber reserved for the single leaning LP + spindle (the one accent).
  • ✗ Don't recolour the spines or add a second amber element.
  • ✗ Don't stretch, rotate, or add effects/shadows.
  • ✗ Don't fuse the year range into the wordmark — it's a tagline.
